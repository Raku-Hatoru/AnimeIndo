# AnimeIndo

##  Deskripsi Aplikasi
Aplikasi ini berisi list anime yang digunakan untuk melihat preview dari suatu anime dari yang teratas atau yang topnya atau yang sedang tayang pada musim ini dan bisa melakukan pencarian atau search.

## Struktur MVVM
MVVM memisahkan data (Model), logika bisnis UI (ViewModel), dan tampilan deklaratif Compose (View) secara terstruktur, reaktif, serta terisolasi.


## Penggunaan API
Aplikasi menggunakan Retrofit2 untuk mengonsumsi Tenrai API (v1) secara asinkron dengan Kotlin Coroutines dan deserialisasi JSON otomatis.
